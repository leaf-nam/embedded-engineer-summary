# 임베디드기사 개념 요약집 사이트

임베디드기사 필기·실기 출제기준을 정리한 요약집 마크다운 한 파일을
**챕터 → 절 → 개념** 단위의 정적 페이지로 자동 분리합니다.

## 사용법
1. 요약집 원본을 `content/summary.md` 로 저장합니다.
2. `pip install markdown && python build.py` → `site/` 폴더가 생성됩니다.
   `site/index.html` 을 열어 로컬에서 확인합니다.
3. GitHub에 push 하고 **Settings → Pages → Source: GitHub Actions** 로 설정하면
   `main` 에 push 할 때마다 자동 배포됩니다.

## 분리 규칙 (원본 제목 레벨)
| 마크다운 | 페이지 |
|---|---|
| `# 1. 제목` | 챕터 (`ch1.html`) |
| `## 1.1 제목` | 절 (`ch1-1.html`) |
| `### 1) 제목` | 개념 (`ch1-1-1.html`) |

파일명은 문서 순서대로 붙습니다. 제목 순서를 바꾸면 파일명도 바뀝니다.

## 수록 범위
- **1. 임베디드 하드웨어** — 논리회로, 컴퓨터 구조와 마이크로프로세서, 주변장치
- **2. 임베디드 펌웨어** — 펌웨어·부트로더, OS 포팅, 디바이스 드라이버
- **3. 임베디드 플랫폼** — 운영체제, 리눅스 커널, 시스템·네트워크 프로그래밍
- **4. 임베디드 소프트웨어** — 자료구조·C·객체지향·안드로이드, 개발도구·테스팅, 소프트웨어공학
- **5. 실기 필답 대비** — 회로 분석, 성능·구조 분석, 장애 대응
- **6. 기출 기반 필수 암기** — 계산 공식, 혼동 개념, 리눅스 명령어
- **7. 학습 우선순위**

## 개념 확장하기
- `python build.py --stubs` 로 모든 페이지의 확장 노트 파일(`extra/<파일명>.md`)을 만듭니다.
- 예: `extra/ch2-1-2.md` 에 쓴 내용은 해당 페이지 하단 「확장 노트」에 표시됩니다.
- 수식은 `\( ... \)`(인라인), `$$ ... $$`(블록)을 씁니다.
- 원본 `summary.md` 는 건드리지 않아도 되므로, 요약집을 새 버전으로 교체해도 확장 노트가 유지됩니다.

## 기출 문제
- **2015~2025년 실기 복원문제 200문항**을 `content/exams.json` 에 연도별로 저장합니다.
- `exams.html` 에서 연도 목록을 보고, `exams-2015.html` … `exams-2025.html` 페이지에서 해당 연도 문제와 정답을 확인합니다.
- 사이드바 목차와 「세부 항목」 목록에는 항목별 기출 문항 수가 뱃지로 표시됩니다(하위 항목 합계).
- 개념 페이지 제목 옆에는 출제 연도 뱃지가 붙고, 본문 아래에 해당 개념의 기출 문제가 표시됩니다.
- 원본 PDF(`*.pdf`)는 저작권·용량 문제로 `.gitignore` 에 등록되어 저장소에 올라가지 않습니다.
  문항 데이터는 PDF에서 추출해 `exams.json` 으로만 커밋합니다.

## 기출 데이터 수정하기
- 각 문항의 `concept` 값은 `summary.md` 의 개념 제목(`### 1) …`)과 **정확히 같아야** 합니다.
  일치하는 개념이 없거나 `concept` 를 비우면 경고 없이 연도 페이지에만 표시됩니다.
- `question` 안의 코드는 ```` ``` ```` 블록으로 감싸면 문제 카드에서 코드로 렌더링됩니다.
- `answer` 는 문자열 또는 문자열 배열이며, 마크다운(표·코드·목록)을 사용할 수 있습니다.
- `note` 를 추가하면 문제 아래에 복원 상태 같은 안내 문구가 표시됩니다.

```json
{
  "exams": [
    {
      "year": 2015,
      "label": "2015년 실기",
      "items": [
        {
          "no": 1,
          "concept": "1) 컴파일러·링커·디버거",
          "question": "프로그램 실행 중 … 연결하는 링크 방식은?",
          "answer": ["**동적 링킹(Dynamic Linking)**", "", "- 설명 …"],
          "note": "복원 문항"
        }
      ]
    }
  ]
}
```
